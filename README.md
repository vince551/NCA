# Kenya Children Assembly — NCA

A modern, mobile-first digital platform for the Kenya Children Assembly (NCA): representation, children's rights, leadership, participation, events, resources and a safe route to speak up.

## Stack

- Semantic HTML5
- Modern CSS
- Vanilla JavaScript modules
- PWA: Web App Manifest + Service Worker
- GitHub Pages deployment via GitHub Actions

## Scope

This repository contains the public-facing platform. Sensitive reporting and authentication should be connected to a verified backend before production use.
